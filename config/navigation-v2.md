## URL Structure (Complete)

### Pages

| Page | URL | Purpose |
|------|-----|---------|
| Homepage | `/` | Craft-first landing |
| Craft Hub | `/pages/craft` | Main craft entry |
| Heat Press | `/pages/heat-press` | Heat press landing |
| Stickers + Transfers | `/pages/stickers-transfers` | Sticker/transfer landing |
| Diamond Painting | `/pages/diamond-painting` | Diamond painting landing |
| Work Surfaces | `/pages/work-surfaces` | Mats/pads landing |
| Bulk + Wholesale | `/pages/bulk-wholesale` | B2B landing |
| Custom Printing | `/pages/custom-printing` | Quote-first experience |
| Learn Hub | `/pages/learn` | Educational hub |
| Size Finder | `/pages/size-finder` | Interactive tool |
| About | `/pages/about` | Company info |
| Contact | `/pages/contact` | Support |
| Shipping & Returns | `/pages/shipping-returns` | Policies (single page) |

### Collections

| Collection | URL | Contains |
|------------|-----|----------|
| All Craft | `/collections/craft` | All craft products |
| Release Paper | `/collections/release-paper` | All release paper |
| Release Paper - Stickers | `/collections/release-paper-stickers` | 8.5x11, small packs |
| Release Paper - Diamond | `/collections/release-paper-diamond-painting` | 4x4, 4.5x4.5 squares |
| Release Paper - Transfers | `/collections/release-paper-transfers` | Letter/legal sizes |
| PTFE Sheets | `/collections/ptfe-sheets` | Pre-cut cover sheets |
| PTFE Rolls | `/collections/ptfe-rolls-bulk` | Bulk rolls only |
| Silicone Mats | `/collections/silicone-mats` | All mats/pads |
| Bundles | `/collections/bundles` | Curated bundles |
| Best Sellers | `/collections/best-sellers` | Top products |
| New Arrivals | `/collections/new` | Recent additions |

### Packaging Lane (Separate)

| Collection | URL | Contains |
|------------|-----|----------|
| Packaging | `/collections/packaging` | All packaging |
| Glass Jars | `/collections/glass-jars` | Jars |
| Child-Resistant | `/collections/child-resistant` | CR packaging |
| Easy-Open | `/collections/easy-open` | Standard lids |

**Rule:** Packaging collections are NOT linked from craft navigation.
