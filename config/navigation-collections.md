# Navigation and Collection Structure

This document defines the recommended navigation menu and Shopify collection structure for Kraft & Kitchen, optimized for craft shoppers.

---

## Current Issues

1. **Material-forward navigation**: Menu says "PTFE and FEP Nonstick," "Nonstick Paper" - craft shoppers think in tasks, not materials
2. **Bulk-first presentation**: Products surface large quantities first, intimidating hobby crafters
3. **Mixed terminology**: Industrial and cannabis language mixed with craft terminology confuses positioning

---

MAIN MENU
├── Craft Supplies ← Primary craft entry point

## Implementation Steps

### In Shopify Admin:

1. **Create new collections** using definitions above
2. **Add collection descriptions** and images
3. **Set collection SEO** (title, description)
4. **Assign products** to appropriate collections
5. **Pin featured products** to collection tops
6. **Update navigation menu** to new structure
7. **Add "Shop by Craft" mega menu** if theme supports
8. **Create Craft Hub page** at `/pages/craft-supplies`
9. **Link collections from Craft Hub**

### Testing:

- Verify all collection URLs work
- Check mobile navigation UX
- Confirm products appear in correct collections
- Test search for craft terms (should surface relevant collections)

---

## Collection Filtering

Enable these filters on collections:

**PTFE Cover Sheets:**
- Size (16x20, 18x20, 15x15, 12x15)
- Thickness (3 mil, 4 mil)
- Pack size

**Silicone Release Paper:**
- Size (Letter, Legal, 4x4 squares)
- Coating (Single-sided, Double-sided)
- Pack size

4. Learn
