## Page Structure Template

All pages follow this structure:
1. **Header** - H1 title + intro paragraph
2. **Table of Contents** - Jump links to sections
3. **Educational Sections** - 4-8 sections with H2 headings
4. **Comparison Tables** - Where applicable
5. **Shop CTA** - Links to relevant products
6. **Schema Markup** - Article schema for SEO

## SEO Implementation Checklist

For each page:

- [ ] Create page in Shopify Admin → Pages
- [ ] Set URL handle to match filename (without .html)
- [ ] Add SEO title (from comment at top of file)
- [ ] Add SEO description (from comment at top of file)
- [ ] Copy HTML content into page body (or use Shopify sections)
- [ ] Verify all product links work
- [ ] Add to navigation under "Learn" menu
- [ ] Link from relevant product pages
- [ ] Submit URL to Google Search Console

## Keyword Notes

**Language preferences for craft shoppers:**
- "Teflon sheet" (brand name, commonly used) → Use "PTFE (commonly called Teflon)"
- "Cover sheet" preferred over "roll" for finished products
- "Release paper" or "non-stick paper" for silicone paper
- "4x4 squares" is the standard for diamond painting

**Terms to avoid in craft context:**
- Industrial terminology
- Overly technical specifications
- Bulk-first language (save for business pages)
