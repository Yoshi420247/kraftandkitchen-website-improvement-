# Photography Prompts - Complete Specification

Based on competitive analysis and build specification requirements.

---

## Global Rules

Every product requires:
1. White background pack shot
2. Macro texture shot
3. Scale shot (in-hand or with ruler)
4. In-use shot
5. 3-step how-to images (or single 3-panel image)
6. 6-10 second loop video

## File Specifications

- **Minimum resolution:** 2000px shortest side
- **Color profile:** sRGB
- **Format:** JPG for photos, PNG for graphics
- **Naming convention:** `kk_{category}_{sku}_{shot-type}_v01.jpg`

## Video Shot List (6-10 Second Loops)

### PTFE Cover Sheet Video

```
6-second loop:
1. Hands pick up PTFE sheet (0-1s)
2. Place over design on garment (1-3s)
3. Heat press closes (3-4s)
4. Heat press opens, sheet lifted to reveal clean press (4-6s)
Loop seamlessly back to start.
```

### Sticker Peel Video

```
6-second loop:
1. Hand approaches sticker on release paper (0-1s)
2. Fingers peel sticker up - satisfying clean release (1-4s)
3. Sticker placed back down (4-6s)
Loop back to start.
```

### Diamond Painting Squares Video

```
8-second loop:
1. Hand removes release paper square from section (0-2s)
2. Applicator pen places 4-5 diamonds (2-5s)
3. Square placed back over section (5-8s)
Loop back to start.
```

### Silicone Mat Cleanup Video

```
6-second loop:
1. Cured resin/glue on mat (0-1s)
2. Hand peels it up cleanly (1-4s)
3. Clean mat surface revealed (4-6s)
Loop back to start.
```
